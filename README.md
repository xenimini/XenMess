# XenMess

Локальный мессенджер на **Tauri 2** + **Vue 3** + **TypeScript**.

История сообщений хранится локально в SQLite. Поддерживает несколько пользователей, темы оформления, эмодзи и реакции.

## Возможности

- Отправка и редактирование текстовых сообщений
- Два локальных пользователя (переключение «от чьего имени» пишешь)
- Фиксированные стороны сообщений (каждый автор всегда на своей стороне)
- Темы оформления: Зелёная, Голубая, Оранжевая
- Эмодзи и реакции на сообщения
- Просмотр профиля участника (клик по аватарке или имени)
- Локальное хранение в SQLite

## Технологии

- **Frontend**: Vue 3, TypeScript, Vite
- **Backend**: Tauri 2 (Rust)
- **База данных**: SQLite (`tauri-plugin-sql`)

## Требования

- [Node.js](https://nodejs.org/) (рекомендуется LTS)
- [Rust](https://www.rust-lang.org/tools/install)
- Для Windows: WebView2 (обычно уже установлен)

## Запуск в режиме разработки

```bash
npm install
npm run tauri dev
```

## Сборка

```bash
npm run tauri build
```

Готовое приложение появится в `src-tauri/target/release/bundle/`.

## Структура

```
src/                  # Vue-приложение
  components/         # Компоненты (сообщения, эмодзи, темы и т.д.)
  types/              # TypeScript-типы
src-tauri/            # Rust-бэкенд Tauri
  migrations/         # SQL-миграции
```
